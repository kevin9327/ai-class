# 카드뉴스 생성기

`cards.json` 의 글만 고치고 `python make_cards.py` 를 돌리면
1080×1080 PNG 가 `out/` 에 다시 만들어집니다. 사이트와 같은 팔레트·서체를 씁니다.

```
python make_cards.py
```

- 결과: `out/card-01.png` … + `out/preview.html`(전부 한눈에 보기)
- 필요한 것: Playwright + Chromium (이 PC에는 이미 설치돼 있음)
- 서체는 Pretendard 를 CDN 에서 받으므로 **생성할 때 인터넷이 필요**합니다

## 카드 종류

| type | 배경 | 쓰임 |
|---|---|---|
| `cover` | 남색 | 첫 장 |
| `body` | 흰색 | 본문. `no` 는 주제 라벨(숫자 아님) |
| `quote` | 남색 | 정리·인용 |
| `cta` | 남색 | 마지막 장. `action` 에 주소 |

## 올릴 곳

인스타그램·스레드는 1080×1080 그대로 올라갑니다.
네이버 카페·블로그도 같은 파일을 씁니다.

**주의**: 없는 실적·후기·수강생 수를 쓰지 않습니다. 사이트와 같은 원칙입니다.
