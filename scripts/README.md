# 영상 원고 (NotebookLM 소스)

`lesson-1.md` ~ `lesson-8.md` 는 **NotebookLM에 넣을 소스 원고**입니다.
영상 자체는 NotebookLM이 만들지만, 무엇을 말할지는 이 원고가 정합니다.
소스가 부실하면 결과물도 일반론이 됩니다.

## 만드는 순서

1. https://notebooklm.google.com 에서 **새 노트북** 생성 (강의 1편 = 노트북 1개)
2. 소스 추가 → 해당 `lesson-N.md` 붙여넣기
3. **Video Overview → Explainer** 선택
   - 한국어는 **Explainer 형식만** 지원합니다 (Cinematic·Short는 영어 전용)
   - 출력 언어를 한국어로 지정
4. 생성 완료까지 30분 이상 걸릴 수 있습니다
5. **다운로드**(MP4) → 유튜브에 업로드(미등록 또는 공개)
6. 유튜브 영상 ID를 `assets/lessons.js` 의 해당 강의 `yt` 에 넣고 `len` 도 실제 길이로 수정

## 알아둘 것

- **무료 한도: 하루 3편.** 8편이면 사흘에 나눠 만듭니다.
- 첫 편을 만든 뒤 **워터마크·브랜딩이 찍히는지 반드시 확인**하세요.
  무료 등급에 표시가 붙는다는 이야기가 있으나 공식 문서에서 확인되지 않았습니다.
  찍힌다면 그대로 두거나(무료 강의이므로 문제 적음) 유료 등급을 검토합니다.
- 생성된 내용은 **사실 확인 후 올립니다.** AI 생성물이라 수치·고유명사가 틀릴 수 있습니다.
- 원고에 **회사 내부 자료나 고객 정보를 넣지 마세요.**

## 원고를 고칠 때

말투는 사이트와 같은 톤(존댓말, 단정적, 과장 없음)을 유지합니다.
없는 실적·후기·수강생 수를 지어내지 않습니다.
